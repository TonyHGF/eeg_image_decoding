# 两个 CLIP 图像分支的排名融合

2026-09-29，十被试全部完成。仅 CN-CLIP RN50 图像分支和 OpenAI CLIP RN50 图像分支各占 0.5；两个文本分支权重为零。复用此前服务器提取并校验过的排名缓存，在本地 CPU 完成全部评估，无重新训练或 GPU 作业。

验证集选出 C=5/3、L=10。测试 Top-1 为 **53.00%**，比 CN 图像单分支提高 **2.65 个百分点**，比 OpenAI 图像单分支提高 **5.70 个百分点**。

## 规则与复现

沿用归一化截断 RRF：V(j)=0.5*(C+1)/(C+r_CN(j))*I(r_CN<=L)+0.5*(C+1)/(C+r_OpenAI(j))*I(r_OpenAI<=L)。分数并列后按两个图像分支平均完整名次、真实候选 ID 决胜。选中的 ID 同时对应图像与固定描述；文本不参与投票或并列决胜。

候选 C={1,4/3,5/3,2}，L={5,10}，共 8 组；按十被试平均验证 Top-1、验证 Top-5、配置顺序选参。每被试验证 740 查询，各含正确项及固定的 199 个干扰项；测试 200 查询，每条对全部 200 个候选检索。每个后端使用验证损失最低的单个 checkpoint，基线亦如此。

```powershell
python scripts/evaluate_rank_fusion.py --config configs/image_rank_fusion.json --extraction-config configs/rank_fusion.json --ranks .hpc-runs/fusion/ranks --captions .hpc-runs/results/shared-qwen-captions.jsonl --output .hpc-runs/fusion/images
```

输出目录必须不存在既有 summary.csv。新配置仅修改投票设置；原始提取配置、排名文件、描述 SHA256 仍严格检查，分支顺序、checkpoint 规则、候选数和种子必须一致。

## 核验与解释边界

2,000 次测试中，相对 CN 图像，融合纠正 202 次错误，同时造成 149 次新增错误，净增加 53 次正确，得到 1,060/2,000=53.00%。当前两图像分支的互补收益超过干扰。

所有十被试均核验：将两个文本分支完全移除后，融合的全部排序和票分与零权重实现完全一致。16,000 条输出的候选 ID、图像路径、配对描述及正确性全部核对通过。基础融合单元测试 4 项通过；排名及描述哈希通过。来源审计保存在 selection.json，逐样本核验计数见 diagnostics.json。

这是看过前轮测试结果后提出的探索性后续分析；同一测试集、单种子、被试内设置，没有新增独立确认集，不作显著性或跨被试泛化结论。两个模型的训练过程仍包含原仓库的图文目标，本次仅在最终决策阶段移除文本分支。继承原 GAT 批处理限制。此前三检查点指标平均不能与本次单检查点基线混用。
