# CN-CLIP 与 OpenAI CLIP RN50：十被试完整对照

2026-09-29，三组各 10 个被试全部完成，Slurm 均为 `COMPLETED`、退出码 `0:0`。

在相同新生成英文描述、数据划分和训练设置下，把 CN-CLIP RN50 换成 OpenAI CLIP RN50 后，图像检索 Top-1 平均下降 **2.83 个百分点**（50.12% → 47.28%）；文本检索 Top-1 平均上升 **6.35 个百分点**（10.93% → 17.28%）。这支持 CN-CLIP 在本次图像检索设置中有优势，但不支持把原方法的全部提升归因于 CN-CLIP，也不支持认为 OpenAI CLIP 在所有指标上更差。

## 三组结果

数值为 10 个被试的均值 ± 样本标准差，单位为百分比；每个被试的数值是三个验证集选中检查点的指标均值。

| 条件 | 图像 Top-1 | 图像 Top-5 | 图像 Top-10 | 文本 Top-1 | 文本 Top-5 | 文本 Top-10 |
|---|---:|---:|---:|---:|---:|---:|
| CN-CLIP 原缓存参考 | 50.27 ± 7.84 | 81.38 ± 6.11 | 90.18 ± 3.82 | 7.65 ± 1.50 | 26.00 ± 3.41 | 39.83 ± 3.12 |
| CN-CLIP 共享描述 | 50.12 ± 8.11 | 81.63 ± 5.87 | 90.33 ± 3.50 | 10.93 ± 2.56 | 31.60 ± 4.89 | 44.45 ± 5.07 |
| OpenAI RN50 共享描述 | 47.28 ± 5.98 | 80.73 ± 4.32 | 89.27 ± 3.18 | 17.28 ± 3.07 | 44.30 ± 5.05 | 60.90 ± 6.44 |

原缓存参考使用作者仓库中四个原始特征文件，其字节身份已核对；所有正式训练共用必要的运行及评估修复。因此它是**原缓存与原模型架构的参考结果，不是未经修改的原代码全量复现结果**。未经修改的原训练代码此前已完成单被试单轮运行，但那个结果仅用于确认流程跑通。

作者仓库未包含原始描述字符串，所以更换编码器的主要比较应看后两行。OpenAI 相对原缓存的图像 Top-1 差值为 −2.98 个百分点，但同时改变了描述来源，不能将这一差值全部归因于编码器。

## 相同描述下的配对差值

定义为 OpenAI-shared − CN-shared，单位为百分点；SD 为十个被试配对差值的样本标准差。

| 指标 | 平均差值 ± SD |
|---|---:|
| 图像 Top-1 | −2.83 ± 3.70 |
| 图像 Top-5 | −0.90 ± 2.54 |
| 图像 Top-10 | −1.07 ± 1.82 |
| 文本 Top-1 | +6.35 ± 1.76 |
| 文本 Top-5 | +12.70 ± 3.00 |
| 文本 Top-10 | +16.45 ± 3.93 |

图像 Top-1：8/10 个被试在 OpenAI 条件下降，2/10 上升。文本 Top-1：10/10 个被试均上升。上述标准差不是置信区间，也不代表多随机种子稳定性；本次没有作显著性宣称。

CN-CLIP 更换为共享描述后，图像 Top-1 相对原缓存仅变化 −0.15 个百分点，但文本 Top-1 增加 3.28 个百分点，说明文本结果对描述来源敏感。本实验使用英文描述；OpenAI 文本结果更好是否源自语言适配，尚未做单独消融，不能由本实验确定。

## 固定设置与检查

- THINGS-EEG2 官方预处理版本：10 个被试，每个被试独立训练；16,540 个训练图像中固定划分 740 个验证样本，200 个测试图像。三个条件按被试核对同一数据划分哈希。
- 冻结训练代码 `6702236fe028a1d386fe403b2feacb7e10a08864`；HYBRID EEG 编码器、seed 2023、batch 1000、alpha 0.1、最多 150 轮、原实现的验证损失早停与三个最佳检查点选择。未用测试结果调参。
- 同一被试共用作者提供的 MAE 预训练检查点；各条件均加载相同 67 个状态项，`init_groups T` 防止重新初始化覆盖。保留原架构及损失。
- Qwen2-VL-7B-Instruct 一次生成 16,740 条英文描述并冻结，两个编码器共用完全相同文本。描述 SHA256：`8484f67d9d953538a153dceb37b89d5105d4f8ac74252c5f1a4bc5cba3f00e35`。
- 两组特征均通过全部图像顺序、split/index、非空唯一描述、共同哈希检查；训练/测试特征分别为 `(16540, 1024)` / `(200, 1024)`，float32、有限值且单位归一化。八个特征文件哈希已记录。
- 使用官方 CN-CLIP RN50 与 OpenAI RN50 权重离线加载。OpenAI 权重哈希已核对；CN 重编码样本与作者原图像缓存余弦相似度约 0.99999 以上。采用各模型配套 tokenizer 与图像预处理；比较的是完整预训练编码器方案，不能单独归因于架构、训练语料或文本塔。

## 解释边界与代码调整

已修复原代码文本路径参数未生效、保存与重载模型封装不一致导致权重可能被跳过、预训练后初始化覆盖等问题，并增加严格加载、每被试独立输出及固定 k-way 候选采样。这些修复对三组保持一致。OpenAI 版本额外使用离线 RN50 加载器、对应 tokenizer/预处理和独立特征路径；没有为它单独调 EEG 模型或超参数。

原 GAT 的边索引批处理限制在三组中一致保留，尚未做修复后的独立消融。原代码所谓 ensemble 是三个检查点**指标的平均**，不是预测融合。文本指标是对 200 个候选图像描述的检索，不应写成通用语义分类准确率。

本次为单种子、被试内实验，并复用作者 MAE 权重。它回答的是这套既定训练流程中更换预训练 CLIP 编码器后的结果；尚不能回答独立多种子、跨被试、重新预训练 MAE、不同语言描述或修正 GAT 后是否仍保持同一差异，也不能证明论文全部模块收益的因果来源。
